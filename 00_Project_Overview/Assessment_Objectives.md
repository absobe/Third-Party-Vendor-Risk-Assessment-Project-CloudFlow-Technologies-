# Assessment Objectives

**This is a fictional cybersecurity case study created for educational and portfolio purposes.**

This simulated engagement is designed to complete the following objectives. Each maps to artifacts in the repository.

| # | Objective | Primary artifacts |
| ---: | --- | --- |
| 1 | Define the vendor relationship | `01_Vendor_Profile/Vendor_Profile.md`, Project Charter |
| 2 | Establish assessment scope | `Scope_and_Assumptions.md` |
| 3 | Define information and systems involved | `Vendor_Data_Flow.md`, `Vendor_Architecture.md` |
| 4 | Develop a vendor security questionnaire | `Vendor_Security_Questionnaire.xlsx` |
| 5 | Generate fictional vendor responses | Same workbook; `Vendor_Response_Summary.xlsx` |
| 6 | Generate fictional evidence artifacts | `03_Vendor_Evidence/*.pdf` |
| 7 | Review the evidence | Evidence mapping workbooks |
| 8 | Evaluate security controls | `Control_Assessment.xlsx` |
| 9 | Identify security gaps | Control results Partially Effective / Ineffective |
| 10 | Create a risk register | `Vendor_Risk_Register.xlsx` |
| 11 | Calculate likelihood and impact | 5×5 model; Python `calculate_risk_scores.py` |
| 12 | Calculate inherent risk | `Inherent_Risk_Assessment.xlsx` |
| 13 | Identify existing controls | Residual workbook column |
| 14 | Calculate residual risk | `Residual_Risk_Assessment.xlsx` |
| 15 | Assign risk ratings | Low / Moderate / High / Critical |
| 16 | Develop remediation recommendations | `Remediation_Plan.xlsx` |
| 17 | Define risk treatment | Mitigate / Accept / Transfer / Avoid |
| 18 | Determine risk acceptance decisions | `08_Risk_Treatment/` |
| 19 | Produce a vendor security scorecard | Weighted 74.4 overall |
| 20 | Produce an executive summary | `10_Executive_Report/` |
| 21 | Produce a final assessment report | `11_Final_Report/` |
| 22 | Produce a professional portfolio README | Root `README.md` |
| 23 | Produce a project presentation | `12_Presentation/` |
| 24 | Make the project reproducible | Scripts, `requirements.txt`, validation |

The assessment also demonstrates TPRM, vendor security assessment, cybersecurity governance, risk identification and analysis, scoring, control assessment, evidence review, treatment, acceptance, remediation planning, business continuity, incident response, access control, data protection, vulnerability management, and executive reporting — all in a **simulated** setting.
