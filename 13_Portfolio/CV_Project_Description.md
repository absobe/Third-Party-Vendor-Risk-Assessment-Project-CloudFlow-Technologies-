# CV Project Description

**Third-Party Vendor Risk Assessment — Personal Cybersecurity Project**

*Simulated GRC / TPRM case study — not a live assessment of a real company.*

- Designed an end-to-end third-party risk management assessment for a fictional SaaS CRM, covering scoping, a 55-question security questionnaire, and evidence review against NIST CSF, ISO/IEC 27001, and SOC 2 concepts used as methodological references.  
- Evaluated control design using explicit ratings (Effective / Partially Effective / Ineffective / Evidence Not Provided) and mapped artifacts to findings VR-001–VR-008.  
- Built a 5×5 inherent and residual risk model (Likelihood × Impact), an Excel risk register with formulas, and a weighted vendor scorecard (overall 74.4) that was deliberately kept separate from the High residual risk rating.  
- Produced remediation plans, risk-treatment and acceptance records, executive reporting, and a Conditional Approval recommendation with contractual security conditions.
