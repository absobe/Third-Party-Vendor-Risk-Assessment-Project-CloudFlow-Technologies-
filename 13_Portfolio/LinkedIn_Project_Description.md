# LinkedIn Project Description

Built a simulated third-party vendor risk assessment for a fictional SaaS provider.

I created a complete TPRM case study in which a fictional financial-services firm (Nexus Financial Services) evaluates a fictional CRM vendor (CloudFlow Technologies). The package includes a security questionnaire, fictional evidence, control assessment, 5×5 inherent/residual scoring, risk register, weighted vendor scorecard, remediation plan, and executive Conditional Approval.

Methodological references included NIST Cybersecurity Framework, NIST SP 800-161 supply-chain risk concepts, ISO/IEC 27001 control concepts, and SOC 2 Trust Services Criteria concepts. The work is educational and is not an audit, certification, or assessment of any real organization.

Skills highlighted: third-party risk, control evaluation, evidence review, risk scoring, GRC reporting.
