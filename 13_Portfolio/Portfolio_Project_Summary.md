# Portfolio Project Summary

**This is a fictional cybersecurity case study created for educational and portfolio purposes.**

## One-paragraph summary

This repository is a complete simulated third-party vendor risk assessment in which Nexus Financial Services evaluates CloudFlow Technologies’ CloudFlow CRM. It includes a 55-question questionnaire, fictional evidence PDFs, control ratings, a 5×5 inherent/residual model, an Excel risk register with formulas, remediation and acceptance records, a 74.4 weighted scorecard, executive reporting, and Python validation. Overall residual risk is High; the recommendation is Conditional Approval.

## What to show in interviews

1. Traceability matrix (finding → control → question → evidence → treatment).  
2. Why 74.4 still equals High residual risk.  
3. Why the vendor was not rejected (data scope + design strengths).  
4. Difference between SOC 2 Type I and Type II as used in VR-005.  
5. Validation script output.

## Honest framing

Say: “I built a simulated TPRM case study for a fictional SaaS provider.” Do not imply employment by Nexus or CloudFlow, and do not imply a real company was assessed.
